# Wiki 到教學 HTML 的執行規格

觸發：新來源、主題或逐頁稿變更。目標：只用 Wiki 產出十四頁有引用、可操作的入門教學。限制：不改 raw、不補外部事實、不改無關頁、不假稱人工核准。

1. 讀 AGENTS.md 與需求摘要。本人未確認時只可依已授權的缺席假設產生可審閱稿，保持待辦。
2. 取得來源、記錄正文核讀與快取結果，至少五篇不同資料。
3. coding agent 讀來源、編寫 Wiki；工具整理來源頁、跨來源頁、index 與 append-only log。
4. `python tools/wiki.py lint`。至少三個相關概念頁，雜湊與連結錯只退相應 Wiki 頁。
5. Query 先讀索引再取頁；回答寫進 queries，卡片僅可讀命中頁。
6. 用卡片寫大綱與逐頁稿，請新的獨立 AI 只讀成品與來源審查。不能用作者自評代替。
7. `python tools/render.py` 和 `python tools/build_portal.py`。不得改逐頁稿任何文字。
8. `python tools/check.py` 與真實瀏覽器檢查。引用/忠實度錯只回該頁稿；排版錯回 renderer；若文字本身太長回逐頁稿。
9. 保存真正的 stdout、時間、退出碼、檢查與反思，再打包。未通過不發布成正式已驗收版本。

局部 loop 最多兩輪；整體最多三輪。通過即停止；證據不足、重大錯誤未解或達上限也停止，列明待辦。流程由 coding agent 執行，檔案是狀態；這不是在瀏覽器內常駐、自行呼叫模型的 agent 服務。
